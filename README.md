# Nikolai Konrad Böhmer · Character Archive

Independent creative archive for **Nikolai Konrad Böhmer** (Nik / Niko), an original fictional Facebook roleplay character. This repository is separate from Bunny's archive.

## Status rules
- **CANON:** explicitly established by the writer.
- **SELECTED / PENDING REVIEW:** supplied in a worksheet but not yet explicitly approved as canon.
- **PROPOSED:** possible addition, not fact.
- **UNKNOWN:** not established.
- **RESEARCHED:** externally verified information with sources.

Never turn proposals into canon silently, or dictate other writers' characters. Real-person faceclaim **Gia Fratte (@giafratte)** is visually referenced only; no reference photographs are stored here.
